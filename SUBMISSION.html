What it is

PetroConnect is a closed marketplace exclusively for verified employees of Kuwait's nine K-Companies (KPC, KOC, KNPC, KIPIC, PIC, KGOC, KUFPEC, KOTC, KAFCO, Q8). Registration is gated by corporate email at both the UI and database layers — no public signups, no anonymous accounts. The full trade loop is implemented: list → chat → structured offer → reserve → payment → mark sold → post-trade review.

Core Features

1
Verified-only access

Corporate-email gate enforced by Postgres trigger. Anonymous role: zero reach.

2
Marketplace

Products, services, service-requests with full-text + semantic search and filters.

3
AI listing assistant

Auto title, description, category, and fair-price suggestions powered by OpenRouter.

4
Duplicate & fraud guard

1536-dim embeddings via pgvector + a JSON-strict LLM fraud classifier.

5
Realtime chat

Supabase Realtime, structured Offer cards with Accept/Decline, optimistic updates.

6
AI message moderation

Every message is scanned post-send; flagged messages surface in the admin queue.

7
Trust System v2

Composite score → 4 tiers (Newcomer · Trusted · Pro · Elite) with animated badges.

8
Payment workflow

Mock provider works today; MyFatoorah / Tap / KNET adapters ready to plug in.

9
Admin command center

Health gauge, revenue charts, transaction log, AI-flagged-message moderation.

10
Command palette (⌘K)

Global search across listings, members, and routes with keyboard navigation.

How to evaluate (~5 minutes)

  1. Open the live platform — review the landing page (animated stats, trust deep-dive) and the /trust page.
  2. Sign in as Ahmed (member). Open any listing, press ⌘K for the global command palette.
  3. Click Message seller → use the tag icon in the composer to send a structured offer (e.g. 8000 KWD).
  4. Switch to Fatma (admin) → open /chat → Accept Ahmed's offer (listing auto-reserves).
  5. Back as Ahmed → click Proceed to payment → confirm → land on /payment/success with full receipt.
  6. As Fatma → visit /admin → Marketplace Health gauge, KPIs, revenue charts, payments table, moderation queue.
